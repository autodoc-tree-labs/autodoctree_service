# B-0601 — Local Embedding Provider 도입 (Ollama, bge-m3/e5)

## Goal
로컬 Ollama 기반의 ‘진짜’ 임베딩을 생성해 semantic 유사도 신호를 확보하고 트리 품질을 개선한다.

## Why
현재 local-stub-v1 + lexical fallback은 의미 기반 묶음을 만들지 못해 ‘단어 폴더’가 생긴다.

## Scope
- EmbeddingProvider 확장: `ollama-embed-v1`
- 설정 키 추가:
  - `embedding.provider=ollama`
  - `embedding.ollama.baseUrl=http://localhost:11434`
  - `embedding.ollama.model=bge-m3`
  - `embedding.ollama.timeoutMs=5000`
  - `embedding.ollama.batchSize=32`
- 배치 임베딩 지원(문서/섹션/요약)
- 타임아웃/재시도/서킷브레이커
- 실패 시 stage FAILED + 재처리 가능(기존 outbox/worker 연동)

## Non-goals
- 외부 임베딩 API 호출
- 임베딩 모델 학습/파인튜닝

## Acceptance Criteria
- stub 없이 임베딩 stage가 수행됨(설정으로 확인)
- 문서 200개 기준 트리 rebuild 결과가 토큰 편향에서 벗어나 ‘주제 묶음’이 나타남(수동 검증)
- 임베딩 장애 시에도 파이프라인이 안전하게 실패/재시도/DLQ로 수렴

## Testing
- unit: OllamaClient mock으로 success/timeout/retry 검증
- integration(옵션): profile `local-llm`에서 실제 ollama 호출 smoke

## Observability
metrics: embedding_latency_ms, embedding_fail_total, embedding_batch_size / logs: ws_id, doc_id, model, duration (content 금지)

## Rollout / Rollback
feature flag: `feature.embedding_ollama=true` / rollback: provider를 stub로 되돌리기

## Notes
임베딩 입력 전처리/캐시는 하위 티켓(B-0601a/B-0601b)로 분리.
