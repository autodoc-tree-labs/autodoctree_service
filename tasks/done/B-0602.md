# B-0602 — Korean Tokenization fallback (JVM) + stopwords/ngram

## Goal
OpenSearch 의존이 어려운 환경에서도 토큰 품질을 확보하는 JVM fallback을 제공한다.

## Why
트리 생성 시 OS 장애/미기동 상황에서도 최소 품질을 유지해야 한다.

## Scope
- tokenizer 모듈화(인터페이스): NoriAnalyzeTokenizer / FallbackTokenizer
- fallback 구현:
  - 간단 lemma 근사(규칙) + stopwords
  - ngram(2~3) 생성
- 설정으로 우선순위 선택 가능

## Non-goals
- 완전한 형태소 분석기 내장(필요 시 별도 라이브러리 검토)

## Acceptance Criteria
- OS 미기동에서도 트리 생성이 실패하지 않고 degrade 된다

## Testing
- unit: fallback tokenizer regression

## Observability
- metric: tokenizer_fallback_used_total

## Rollout / Rollback
- 설정으로 fallback only 가능

## Notes
가급적 B-0608이 주 경로.
