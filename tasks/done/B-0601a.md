# B-0601a — Embedding 입력 전처리 v1 (대표 텍스트 생성/길이 제한)

## Goal
임베딩 입력이 짧거나 길어 품질이 흔들리는 문제를 완화하고, 민감 정보 로깅을 차단한다.

## Why
긴 문서는 잘려 의미가 손실되고, 짧은 문서는 노이즈에 취약하다.

## Scope
- 임베딩 입력 생성 규칙:
  - title + 상위 N개 섹션 헤더/요약 + 본문 앞/뒤 일부를 조합
  - 최대 길이 제한(예: 4k chars) + 공백/제어문자 정리
- 민감 정보(본문/추출 텍스트) 로그 금지 강제(가드)
- 규칙은 config로 조절 가능(`embedding.input.maxChars` 등)

## Non-goals
- LLM 요약 생성(비용/복잡도)

## Acceptance Criteria
- 동일 문서에 대해 입력이 안정적으로 생성됨(회귀 테스트)
- 너무 짧은 문서에서도 의미 신호가 개선(수동 확인)

## Testing
- unit: 입력 생성 함수에 대한 golden tests

## Observability
- metrics: embedding_input_chars_histogram(옵션). 로그는 길이만.

## Rollout / Rollback
- 설정으로 maxChars 조정/비활성화 가능

## Notes
오프라인 제약상 rule 기반으로만 구현.
