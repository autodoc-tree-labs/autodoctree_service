# B-0608 — 라벨/TF-IDF 토큰 입력을 OpenSearch `_analyze`(ko_nori)로 교체

## Goal
라벨링/lexical feature 생성 시 한국어 형태소 분석 결과를 사용하여 토큰 분열/노이즈 라벨을 줄인다.

## Why
현재 단순 정규화만으로는 한국어 변형(어간/조사)을 충분히 흡수하지 못한다.

## Scope
- TreeAlgorithms 라벨 토큰 추출 단계 교체:
  - 입력: 대표 텍스트(title + excerpt)
  - 처리: OpenSearch `_analyze` with analyzer=ko_nori
  - 출력: tokens(중복 제거/길이/빈도 필터)
- OS 장애 시 fallback: 기존 tokenizer(현재 방식)로 degrade
- content logging 금지(요청/응답 본문 로그 금지)

## Non-goals
- 라벨을 LLM이 직접 생성(후속)
- 완전한 JVM 형태소 분석기 내장(옵션 티켓)

## Acceptance Criteria
- 사랑/사랑하 같은 분열 라벨이 줄어든다
- stopword/조사 위주 라벨 빈도가 감소

## Testing
- unit: analyzer 결과 파싱
- integration: `_analyze` 호출 smoke

## Observability
- metric: nori_analyze_latency/fail_total
- log: ws_id, doc_id, token_count

## Rollout / Rollback
- feature flag `feature.nori_tokenizer=true`
