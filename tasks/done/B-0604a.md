# B-0604a — Large cluster 분해 전략 v1 (sub-community or HAC)

## Goal
커뮤니티가 너무 큰 경우(>max_cluster_size) 2-depth leaf로 안정적으로 분해한다.

## Why
사용자 UX는 2-depth가 목표이며, 너무 큰 폴더는 관리 불가하다.

## Scope
- max_cluster_size 초과 시 2차 분해:
  - 옵션1: sub-community (resolution 조정)
  - 옵션2: HAC(거리 기반)로 k 분할
- leaf 라벨은 B-0603 라벨 정책을 따름

## Non-goals
- 3-depth 이상 트리 생성

## Acceptance Criteria
- max_cluster_size 초과 시에도 leaf로 분해되어 2-depth 유지

## Testing
- unit: large cluster fixture
- integration: 문서 200개 시 leaf 분해 확인

## Observability
- metric: split_cluster_total

## Rollout / Rollback
- 설정으로 분해 정책 선택 가능

## Notes
트리 깊이는 2로 고정.
