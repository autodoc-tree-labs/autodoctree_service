# B-0612a — Lock node semantics 강화(이름/위치 보호)

## Goal
사용자가 잠금한 노드가 rebuild로 변경되지 않도록 안정성을 강화한다.

## Why
트리가 흔들리면 불신이 생기고 제품 가치가 사라진다.

## Scope
- locked node는:
  - label rename 금지
  - membership 이동 최소화(정책)
  - 위치(parent) 변경 금지
- 충돌 시: 추천 스냅샷(RECOMMENDED)로만 생성하고 ACTIVE는 유지

## Non-goals
- 복잡한 merge UI

## Acceptance Criteria
- locked node가 rebuild 후에도 동일 label/위치 유지

## Testing
- integration: lock 후 rebuild 스냅샷 비교

## Observability
- metric: locked_node_preserved_total

## Rollout / Rollback
- 잠금 정책 강도 설정 가능

## Notes
B-0504 안정성 정책과 정합.
