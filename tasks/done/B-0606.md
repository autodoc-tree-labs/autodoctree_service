# B-0606 — Explain Debug Mode: neighbors + signal 분해 (admin only)

## Goal
왜 문서가 그 노드에 배치되었는지/왜 묶였는지 디버깅 가능하게 한다.

## Why
품질 튜닝은 원인 가시화 없이는 불가능하며, 로그로 본문을 남길 수도 없다.

## Scope
- admin endpoint:
  - GET /admin/tree/debug/neighbors?document_id=...
- 응답(본문 없이):
  - neighbor_doc_id, title, sem_sim, lex_sim, entity_overlap, final_sim, gate_flags
- web-admin에 간단 테이블 패널 추가(연동은 A-0613)

## Non-goals
- 사용자용 explain UX 개선(별도 티켓)

## Acceptance Criteria
- UI/응답으로 브릿지 edge, lexical 지배 여부를 확인 가능

## Testing
- unit: response contract
- security: admin only

## Observability
- metric: debug_neighbors_called_total

## Rollout / Rollback
- endpoint는 admin route에만, prod에서도 안전

## Notes
민감 정보(본문/추출텍스트) 절대 반환 금지.
