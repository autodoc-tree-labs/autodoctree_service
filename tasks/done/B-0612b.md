# B-0612b — User rule v1 (엔티티/키워드 → 특정 노드) 최소 구현

## Goal
사용자가 명시 규칙으로 분류를 고정할 수 있게 한다.

## Why
개인화는 학습만으로는 느리며, 강제 규칙이 신뢰/효율을 높인다.

## Scope
- user_rule 테이블 사용(이미 설계되어 있다면 활성화)
- rule_type 예:
  - ENTITY_CONTAINS(value) -> node_id
  - TITLE_CONTAINS(keyword) -> node_id
- rebuild 시 rule 매칭 문서는 해당 노드에 강제 배치(스코어 최상)

## Non-goals
- 복잡한 DSL/우선순위 다단계

## Acceptance Criteria
- 규칙 등록 후 다음 rebuild에서 일관 배치됨

## Testing
- unit: rule matcher
- integration: rule 적용 확인

## Observability
- metric: rules_applied_total

## Rollout / Rollback
- rule 기능은 기본 off 가능

## Notes
초기 UI는 admin에서만 제공해도 됨.
