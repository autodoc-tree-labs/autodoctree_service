# I-0611 — OpenSearch ko_nori analyzer 템플릿 추가 (stoptags/synonyms/userdict)

## Goal
한국어 형태소 기반 분석기(ko_nori)를 표준화하여 검색/라벨 토큰 품질을 올린다.

## Why
조사/어미/활용으로 토큰이 분열되며, 일반어가 라벨이 되는 현상이 잦다.

## Scope
- index template에 analyzer `ko_nori` 추가:
  - tokenizer: nori_tokenizer(decompound_mode=mixed)
  - filter: nori_part_of_speech(stoptags), lowercase, synonym(선택)
- user dictionary 규칙 파일화(프로젝트/제품명 등)
- synonym 파일화(문서/도큐먼트, 정리/분류/폴더링 등)
- DEV_SETUP.md에 템플릿 적용/재인덱싱 가이드

## Non-goals
- 형태소 모델 커스텀 학습
- 외부 사전 다운로드 자동화

## Acceptance Criteria
- 새 인덱스에 ko_nori analyzer가 적용됨
- `_analyze`로 테스트 시 조사/어미가 제거된 토큰이 나온다

## Testing
- integration: `_analyze` 호출 smoke(로컬 OS 구동 시)

## Observability
- N/A(설정 중심)

## Rollout / Rollback
- 템플릿 버전 올리고 alias-swap으로 롤백 가능

## Notes
OpenSearch 이미지에 nori 플러그인이 포함돼 있어야 함.
