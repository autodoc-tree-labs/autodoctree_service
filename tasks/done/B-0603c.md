# B-0603c — ‘기타/미분류’ 정책 v1 (leaf-only)

## Goal
품질 낮은 군집을 안전하게 수용하되 UX를 망치지 않는다.

## Why
모든 문서를 깔끔히 라벨링할 수 없으므로 수용 정책이 필요하다.

## Scope
- 조건:
  - cluster 내부 대표성 점수 < threshold or size < min_cluster_size
- 처리:
  - leaf 라벨을 ‘기타’로 두고 상위는 유지
  - 상위까지 ‘기타’가 되지 않도록 제한

## Non-goals
- ‘기타’ 내부 재분류 자동화(후속)

## Acceptance Criteria
- ‘기타’가 top-level에 나타나지 않음
- 품질 낮은 문서가 트리에서 사라지지 않음

## Testing
- unit: policy function

## Observability
- metric: 기타_cluster_total

## Rollout / Rollback
- threshold 조정으로 정책 변경

## Notes
사용자 피드백/룰이 쌓이면 ‘기타’는 줄어드는 게 목표.
