# B-0601b — Embedding 중복 방지/캐시 v1 (텍스트 해시 기반)

## Goal
동일 입력에 대한 임베딩 재계산을 줄여 rebuild/worker 비용을 낮춘다.

## Why
트리 rebuild 시 동일 문서가 반복 임베딩되면 속도/안정성이 떨어진다.

## Scope
- input_text_hash = sha256(canonical_input + model_version)
- embedding 테이블에 (target_type, target_id, model_version, input_hash) unique 추가 또는 논리적 upsert
- 캐시 hit 시 재호출 없이 기존 벡터 사용
- stage idempotency key에 input_hash 포함

## Non-goals
- Redis 기반 대규모 벡터 캐시(초기 제외)

## Acceptance Criteria
- 동일 문서 재빌드 시 embedding 호출량이 유의미하게 감소
- 모델 버전 변경 시에는 새로 계산됨

## Testing
- unit: hash 계산/업서트
- integration: 2회 rebuild 시 호출 감소 확인(메트릭)

## Observability
- metric: embedding_cache_hit_total/miss_total

## Rollout / Rollback
- unique 제약 도입 시 마이그레이션 포함, 실패 시 롤백 스크립트 제공

## Notes
DB 스키마 변경이 필요하면 Flyway로 반영.
