# I-0701 — Ollama Offline Packaging 강화 (Runtime 고정 + 모델 프리로드 가이드)

## Context
- 오프라인 로컬 운영에서 Ollama runtime/모델 준비 절차가 일관되지 않으면 품질 재현이 어렵다.

## Goal
- `ollama/ollama:0.5.7` 런타임을 유지하면서, embedding/LLM 모델 준비 절차를 compose+문서+스모크로 표준화한다.

## Non-goals
- 클라우드 LLM 연동
- GPU 튜닝

## Scope
- compose `ollama` 서비스 유지/보강(profile `llm`, healthcheck)
- 모델 2개 pull 절차 문서화
  - `bge-m3`
  - `llama3.1:8b-instruct`
- (선택) profile 기반 init 서비스로 모델 pull 자동화
- `scripts/llm_smoke.sh` 추가 (runtime/embed/generate 체크)

## Acceptance Criteria
- [ ] 새 환경에서 compose up + model pull + smoke 성공이 재현 가능
- [ ] 모델 미다운로드/미기동/timeout 각각 명확한 오류 메시지 제공

## Testing
- smoke 스크립트 수동/CI 실행 가능

## Observability
- healthcheck 및 스크립트 로그는 메타 정보만 출력

## Rollout / Rollback
- profile 기반이라 기본 비활성 유지, 필요 시에만 활성화

## Security / Privacy
- 테스트 payload는 샘플 문구만 사용, 사용자 데이터 비사용
