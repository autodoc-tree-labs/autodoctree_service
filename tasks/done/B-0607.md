# B-0607 — Tree Quality Regression Suite (offline golden set)

## Goal
알고리즘 변경으로 인한 트리 품질 회귀를 자동으로 감지한다.

## Why
파라미터/토크나이저/클러스터링은 회귀가 빈번하며 수동 검증은 놓친다.

## Scope
- fixtures: 작은 골든셋(예: 50 docs, 5 주제)
- 테스트 지표(프록시):
  - 금칙 라벨 비율=0
  - 평균 라벨 길이/phrase 비율
  - cluster purity proxy(주제 태그 기반)
  - churn ratio 상한(동일 입력에서 구조 안정)

## Non-goals
- 완전한 품질 자동 채점(ML)

## Acceptance Criteria
- CI/로컬에서 테스트로 회귀 탐지 가능
- 실패 시 diff 리포트 제공

## Testing
- Gradle test suite에 포함

## Observability
- N/A(테스트 산출물로 대체)

## Rollout / Rollback
- golden set 업데이트 프로세스 문서화

## Notes
오프라인 임베딩은 고정 모델 버전이 전제(I-0610).
