# A-0613 — Admin UI: tree debug panel + cluster stats

## Goal
운영자가 트리 품질/원인을 UI로 확인하고 튜닝할 수 있게 한다.

## Why
백엔드 디버그 endpoint만으로는 생산성이 낮고 반복 확인이 불편하다.

## Scope
- Debug Neighbors 화면:
  - document 선택(검색/ID 입력) → neighbors table 표시
- Cluster stats 화면(간단):
  - cluster_count, avg_cluster_size, label_filtered_total 등 주요 지표 표시
- Admin 인증/권한 스코프 유지

## Non-goals
- 일반 사용자 UX 개선

## Acceptance Criteria
- 관리자가 브릿지/혼합 원인을 UI로 파악 가능

## Testing
- Playwright smoke (페이지 로드/테이블 렌더)

## Observability
- front log에 민감정보 금지

## Rollout / Rollback
- feature flag로 메뉴 숨김 가능
