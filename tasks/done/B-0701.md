# B-0701 — Offline Tree Quality Upgrade (Embedding/LLM 분리 + LabelerChain)

## Context
- 현재 트리 품질은 lexical fallback 영향이 커서 의미 기반 군집/라벨 일관성이 부족하다.
- 임베딩/생성 경로가 설정/코드/로그에서 명확히 분리되지 않아 운영 실수가 발생할 수 있다.

## Goal
- 오프라인 로컬 모델 기준으로 임베딩(`bge-m3`)과 생성 LLM(`llama3.1:8b-instruct`)을 완전히 분리하고, 트리 자동정리 품질을 운영 가능한 수준으로 개선한다.

## Non-goals
- 외부 클라우드 LLM/Embedding 사용
- 모델 파인튜닝/학습

## Scope
- 설정 키 분리 (`embedding.*`, `llm.*`, `feature.llm_*`)
- 시작 시 모델 스왑 오구성 fail-fast
- Ollama 클라이언트 분리 구현
  - `OllamaEmbeddingClient` (`/api/embed`)
  - `OllamaLlmClient` (`/api/generate`, `stream=false`)
- Tree rebuild 로그/메트릭 강화
- LabelerChain v1 구현
  1. `LlmLabeler` (primary)
  2. `TitlePhraseLabeler` (deterministic fallback)
  3. `TfidfLabeler` (optional, feature-flag)
- LLM Explain one-liner 추가(기존 rationale JSON 유지)
- 프롬프트 파일 버전관리 (`resources/prompts/label_v1.txt`, `explain_v1.txt`)
- cluster_signature 기반 라벨 캐시 도입(스냅샷 저장)

## API / Contracts
- 외부 API 스키마 파괴적 변경 없음.
- Explain 응답은 기존 필드 유지 + 설명 문장 필드 추가.

## DB / Index changes
- `tree_snapshot`에 라벨 캐시(JSON) 저장 컬럼 추가.

## Happy path
1. 문서 파이프라인에서 임베딩은 `bge-m3`로 생성.
2. rebuild 시 임베딩 기반 neighbor/cluster를 형성.
3. LabelerChain이 라벨 생성(LLM 우선, 실패 시 deterministic fallback).
4. Explain은 기존 근거 JSON + LLM one-liner를 제공.

## Edge cases
- Ollama 미기동/타임아웃 시 재시도 후 실패, stage/status 실패로 노출
- LLM 실패 시 fallback 라벨러로 non-empty 라벨 보장
- feature flag off 시 기존 deterministic 경로만 사용

## Acceptance Criteria
- [ ] 임베딩은 `bge-m3`, 생성은 `llama3.1:8b-instruct`로 분리 동작
- [ ] 모델 스왑 설정 시 앱 시작 즉시 fail-fast
- [ ] rebuild 로그에 provider/model/ratio/edge breakdown 출력
- [ ] LabelerChain fallback으로 항상 non-empty 라벨 생성
- [ ] 본문/첨부/추출 텍스트가 로그/메트릭/디버그 응답에 노출되지 않음

## Testing
- unit: Ollama embed/generate client mock 테스트
- unit: LabelerChain success/fallback 테스트
- unit: fake embedding 기반 2-topic 분리 테스트
- integration(optional): local-llm profile 스모크

## Observability
- metrics: `embedding_latency_ms`, `embedding_fail_total`, `tree_rebuild_duration_ms`, `edges_total`, `edges_filtered_total`, `avg_similarity`
- logs: `workspace_id`, `document_count`, model/provider 메타만

## Rollout / Rollback
- `feature.llm_labeling`, `feature.llm_explain`로 점진 적용
- rollback은 플래그 off + provider/모델 기본값 복원

## Security / Privacy
- 문서 body/chunk/attachment/extracted text 로깅 금지
- 프롬프트 입력은 title + 짧은 excerpt/신호 메타만 사용
