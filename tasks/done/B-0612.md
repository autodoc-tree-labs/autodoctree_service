# B-0612 — Feedback 기반 Routing policy v2 (move/rename 반영)

## Goal
사용자 드래그/이름변경 피드백으로 자동 분류가 점점 수렴하도록 개인화한다.

## Why
정답 폴더가 없으므로 반복 피드백으로 수렴하는 루프가 핵심 제품 가치다.

## Scope
- feedback_event를 학습 신호로 사용:
  - 특정 토큰/엔티티/임베딩 근접 문서에 가중
- 다음 rebuild 시 membership score에 피드백 가산
- 간단 룰(고정) + 가중치(선호) 혼합

## Non-goals
- 온라인 학습/복잡한 모델 학습

## Acceptance Criteria
- 5~10회 드래그 후 추천 노드가 눈에 띄게 개선(수동)
- 피드백은 테넌트/사용자 스코프 준수

## Testing
- unit: scoring delta
- integration: feedback 반영 rebuild

## Observability
- metric: feedback_applied_total, corrected_ratio

## Rollout / Rollback
- feature flag `feature.feedback_routing_v2=true`

## Notes
잠금 노드/룰과 결합 시 효과 큼(B-0612a/b).
