# B-0604 — Community detection clustering(Leiden/Louvain)으로 교체

## Goal
connected component 기반 혼합을 줄이고 주제 중심 커뮤니티로 자연스럽게 묶는다.

## Why
연결요소는 브릿지 문서 하나로 전체가 섞일 수 있어 트리 품질이 급락한다.

## Scope
- clustering 단계 교체:
  - 입력: weighted neighbor graph
  - 출력: communities = top-level clusters
- 가능한 라이브러리 선택 후 적용(없으면 자체 구현 간소 버전)
- 설정: community.resolution, min_cluster_size

## Non-goals
- 대규모 분산 그래프 처리

## Acceptance Criteria
- 브릿지 문서로 전체가 합쳐지는 사례 감소
- 50~200 문서에서 납득 가능한 주제 묶음 형성

## Testing
- unit: 고정 그래프 fixture로 결과 검증
- integration: rebuild 성공

## Observability
- metric: cluster_count, avg_cluster_size, modularity_proxy

## Rollout / Rollback
- feature flag `feature.community_clustering=true`
