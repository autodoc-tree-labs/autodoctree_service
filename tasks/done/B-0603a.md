# B-0603a — Phrase-based label 후보 생성(ngram/compound)

## Goal
단일 토큰이 아닌 ‘구(phrase)’ 중심 라벨 후보를 생성한다.

## Why
폴더명은 보통 단어 1개보다 2~3단어 구가 더 납득 가능하다.

## Scope
- tokenizer 결과로 2~3gram 후보 생성
- 점수화에 coverage/대표성 반영
- 너무 긴 라벨은 컷(예: 20자)

## Non-goals
- 문장형 라벨 생성

## Acceptance Criteria
- 라벨의 평균 길이/구체성이 상승

## Testing
- unit: ngram 후보 생성

## Observability
- metric: phrase_label_used_total

## Rollout / Rollback
- 설정으로 ngram off 가능
