# I-0614 — Tree 품질/성능 Metrics + Dashboard 초안

## Goal
트리 rebuild/클러스터/라벨 품질을 숫자로 관측 가능하게 만든다.

## Why
‘잘 됨/안 됨’을 정량화해야 튜닝과 운영이 가능하다.

## Scope
- metrics 정의/수집:
  - tree_rebuild_duration_ms
  - neighbor_edges_total, edges_filtered_total
  - cluster_count, avg_cluster_size
  - label_filtered_total(by_reason), avg_label_length
  - churn_ratio, moved_ratio
- Grafana 대시보드 JSON 초안 추가(또는 Prometheus query 문서화)

## Non-goals
- 알림 룰 최적화(후속)

## Acceptance Criteria
- rebuild 후 주요 지표가 Prometheus/Grafana에서 확인 가능

## Testing
- N/A(메트릭 노출 smoke)

## Observability
- 로그는 최소, 메트릭은 태그 폭발 방지

## Rollout / Rollback
- 대시보드는 versioned 파일로 관리

## Notes
기존 observability 스택이 없다면 infra ticket으로 확장.
