# B-0603 — Label Quality Filter + fallback 라벨링(금칙/저품질 제거)

## Goal
트리 노드 라벨이 ‘단어 목록’처럼 보이지 않도록 폴더명 품질을 보장한다.

## Why
TF-IDF top token이 곧 라벨이 되면 UX가 무너지고 신뢰가 떨어진다.

## Scope
- 라벨 후보 5개 생성 후 규칙 기반 필터:
  - 너무 짧음(1~2글자), 동사 어간, stopword-only
  - 일반어/금칙어(성적/욕설 등) 사전 기반 필터
- fallback:
  - 대표 문서 제목 기반 phrase 라벨
  - 또는 leaf에만 ‘기타/미분류’ 허용
- 중복 라벨 제거/정규화

## Non-goals
- LLM 기반 라벨 생성(후속)

## Acceptance Criteria
- 금칙 라벨이 트리에 노출되지 않음
- 상위 라벨이 더 구체적으로 생성됨(2단어 이상 비율 증가)

## Testing
- unit: 필터 규칙
- snapshot: 라벨 후보/결과 golden tests

## Observability
- metric: label_filtered_total(by_reason), avg_label_len

## Rollout / Rollback
- feature flag `feature.label_quality_filter=true`

## Notes
Nori 기반 토큰(B-0608)과 결합 시 효과가 큼.
