# B-0605 — Similarity Fusion v2: `max` 제거 + 게이팅 + 가중 결합

## Goal
lexical 신호가 우연히 높아 의미와 무관한 edge가 생기는 문제를 줄여 혼합을 방지한다.

## Why
`max(semantic, lexical)`는 lexical이 브릿지 역할을 하며 큰 컴포넌트를 만들기 쉽다.

## Scope
- fusion 전략:
  - embedding available: sim = w_sem*sem + w_lex*lex (lex는 gate 통과 시만 가산)
  - embedding missing: lexical-only
- lex gate 조건 예:
  - lex > lex_gate AND (shared_entities>=1 OR title_overlap>=1)
- 설정:
  - fusion.w_sem=0.8, fusion.w_lex=0.2, fusion.lex_gate=0.35

## Non-goals
- 학습 기반 fusion(LTR)

## Acceptance Criteria
- 의미 없는 토큰 브릿지 edge 감소
- 트리 혼합 감소(수동 확인)

## Testing
- unit: fusion 함수
- integration: edge 분포 메트릭 비교

## Observability
- metric: edge_created_total(by_reason), avg_sem/avg_lex

## Rollout / Rollback
- 설정으로 기존 max 방식으로 되돌릴 수 있도록 유지(옵션)

## Notes
커뮤니티 클러스터링(B-0604)과 함께 적용 시 효과 극대화.
