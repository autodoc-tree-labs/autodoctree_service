# U-1408 - Workspace launcher multi-account switcher and add-account signup

## Context
- 현재 좌측 상단 런처는 단일 계정 기준 워크스페이스 목록만 제공한다.
- 사용자는 계정별 워크스페이스 그룹과 빠른 계정 전환, 계정 추가(회원가입)를 원한다.

## Goal
- 워크스페이스 런처를 다중 계정 구조로 확장하고, 계정 추가 버튼에서 회원가입/로그인을 지원한다.

## Non-goals
- 계정 프로필 이미지 편집
- 결제/요금제 화면

## Scope
- 세션 저장 구조를 다중 계정 모델로 확장(기존 단일 세션 키 호환 유지)
- 런처에서 계정별 워크스페이스 목록 렌더
- 계정별 `새 워크스페이스` 버튼
- 계정 헤더 `...` 메뉴:
  - `워크스페이스 생성 또는 참여`
  - `로그아웃`
- 하단 액션:
  - `다른 계정 추가` (회원가입/로그인 폼)
  - `모든 계정에서 로그아웃`

## API / Contracts
- 신규 register API 사용
- 기존 workspace/invite API 재사용

## DB / Index changes
- 없음

## Happy path
1. 런처 열기
2. 계정별 워크스페이스 확인 및 전환
3. 다른 계정 추가 → 회원가입 또는 로그인
4. 새로 추가한 계정의 워크스페이스를 즉시 선택/탐색

## Edge cases
- 계정별 토큰 만료 시 해당 섹션 에러 표시
- 마지막 계정 로그아웃 시 로그인 페이지로 이동

## Acceptance Criteria
- [ ] 계정별 워크스페이스가 그룹으로 표시된다.
- [ ] 계정별 새 워크스페이스 생성/참여 동선이 동작한다.
- [ ] 다른 계정 추가 버튼에서 회원가입이 가능하다.
- [ ] 모든 계정 로그아웃이 동작한다.

## Testing
- web-user e2e: 런처 오버플로우/메뉴 렌더
- web-user e2e: 다중 계정 추가/전환 플로우

## Observability
- UI 오류는 사용자 메시지로 표시
- 민감정보(토큰/비밀번호) 로그 금지

## Rollout / Rollback
- 점진 반영 가능(기존 라우팅/문서 기능 유지)
- 롤백 시 세션 모델 + 런처 렌더 로직 revert

## Security / Privacy
- 계정 전환 시 토큰은 로컬 저장소에만 보관
- 비밀번호는 요청 본문 외 저장 금지
