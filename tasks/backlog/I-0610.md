# I-0610 — Ollama 로컬 모델 운영 패키징 (docker compose + 문서화)

## Goal
완전 오프라인 환경에서 임베딩/라벨링 품질을 재현 가능하게 만드는 로컬 LLM(임베딩) 런타임을 표준화한다.

## Why
개발자 환경마다 모델/버전이 달라지면 트리 품질이 흔들리고 디버깅이 불가능해진다.

## Scope
- docker-compose.yml에 `ollama` 서비스(profile: llm) 정의/정리
- healthcheck 보강(ready 상태 확인)
- DEV_SETUP.md에 실행/검증 절차 추가:
  - `docker compose --profile llm up -d ollama`
  - `ollama pull bge-m3` (기본 모델)
  - `ollama list`로 설치 확인
- (선택) 모델 프리로드 스크립트 제공(명령 1줄로 pull)
- 모델/태그 고정 가이드(예: bge-m3:latest 대신 bge-m3:<tag> 권장)

## Non-goals
- 외부 API 사용
- GPU 최적화/클러스터 운영

## Acceptance Criteria
- 새 환경에서 문서만 보고 10분 내 ollama 실행 및 모델 준비 가능
- doc-api/worker에서 임베딩 호출 시 정상 응답(타임아웃 없이)
- ollama 미기동 시 시스템이 명확한 에러/가이드 출력

## Testing
- N/A(인프라/문서 중심). 필요 시 smoke 스크립트 제공.

## Observability
- healthcheck 로그 최소화. 본문/텍스트 로그 금지.

## Rollout / Rollback
- profile 기반이라 기본은 비활성. 필요 시 `--profile llm`로만 활성화.

## Notes
기본 모델 추천: bge-m3(다국어). 대안: multilingual-e5-large.
