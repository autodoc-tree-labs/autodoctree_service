# B-0604b — NeighborBuilder 튜닝 + 메트릭(TopK/threshold/normalize)

## Goal
neighbor 그래프 품질을 측정 가능하게 만들고, 파라미터 튜닝을 안전하게 한다.

## Why
현재는 왜 edge가 생겼는지/부족한지 파악이 어려워 품질 개선 속도가 느리다.

## Scope
- 설정:
  - neighbor.topK, neighbor.minSimilarity, neighbor.normalize
- 메트릭 추가:
  - edges_total, edges_filtered_total, avg_similarity, similarity_histogram
- (선택) self-loop/duplicate edge 방지

## Non-goals
- 자동 튜닝(AutoML)

## Acceptance Criteria
- rebuild마다 edge 통계가 기록되고 튜닝이 가능

## Testing
- unit: 파라미터에 따른 필터 동작

## Observability
- dashboards 후보 지표 명시

## Rollout / Rollback
- default 값은 보수적으로 유지

## Notes
디버그 패널(B-0606)와 시너지.
