# U-1406 — Collapsible editor side panels for wider writing area

## Context
- 문서 편집 화면에서 좌측 워크스페이스 패널과 우측 문서 컨텍스트 패널이 동시에 열리면 본문 에디터 폭이 좁아져 작성 효율이 떨어진다.
- 사용자는 Notion 스타일로 패널을 필요할 때만 열고 닫아 본문 집중 영역을 넓히고 싶어한다.

## Goal
- 좌측/우측 패널을 화살표 버튼으로 토글할 수 있고, 기본 상태는 좌측 열림/우측 닫힘으로 동작한다.

## Non-goals
- 모바일 전용 내비게이션 구조 재설계
- 패널 너비 리사이즈 정책 자체 변경

## Scope
- `Layout` 헤더에 좌측 패널 토글 화살표 버튼 추가
- `WorkspaceDocumentEditorPage` 액션 영역에 우측 컨텍스트 패널 토글 화살표 버튼 추가
- 좌측 패널 기본값 열림, 우측 패널 기본값 닫힘 적용
- 토글 상태에 맞는 레이아웃/CSS 반영
- e2e 회귀 테스트 추가

## API / Contracts
- API 변경 없음

## DB / Index changes
- 없음

## Happy path
1. 사용자가 문서 편집 화면에 진입하면 좌측 패널은 열려 있고 우측 패널은 닫혀 있다.
2. 좌측 화살표 버튼 클릭 시 좌측 패널이 접히고 본문 영역이 넓어진다.
3. 우측 화살표 버튼 클릭 시 문서 컨텍스트 패널이 열린다.
4. 다시 클릭하면 각 패널이 원래 상태로 복귀한다.

## Edge cases
- 패널이 닫힌 상태에서도 토글 버튼은 접근 가능해야 한다.
- 좁은 화면/사이드바 최소폭에서도 레이아웃이 깨지지 않아야 한다.

## Acceptance Criteria
- [ ] 좌측 패널 토글 화살표 버튼이 동작한다.
- [ ] 우측 컨텍스트 패널 토글 화살표 버튼이 동작한다.
- [ ] 기본 상태가 좌측 열림, 우측 닫힘이다.
- [ ] 패널 토글 시 본문 편집 영역이 유의미하게 확장된다.

## Testing
- Unit tests: 해당 없음(UI 상태 중심)
- Integration tests: 해당 없음

## Security / Privacy
